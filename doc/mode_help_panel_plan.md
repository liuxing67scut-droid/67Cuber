# 模式玩法提示框实现计划

## 目标

在三种游戏模式中加入一个轻量提示框，用简短文字说明当前模式的玩法，降低第一次进入游戏页时的理解成本。

第一版先使用代码绘制的木色边框提示框，不引入图片资源。后续如果准备好羊皮纸、木牌等图片素材，可以在不改变业务逻辑的情况下替换绘制外观。

## 已确认方案

- 提示框放在 `ui` 模块，用类封装。
- 第一版先试右下角方块提示框。
- 提示框底部放两个按钮：`知道了` 和 `本次不再提示`。
- `本次不再提示` 只对当前模式生效，只在本次程序运行期间有效；重启程序后恢复默认提示。
- 切换到未被 suppress 的模式时自动显示对应玩法说明。
- 不使用配置文件，不保存用户偏好。

## 设计原则

- 不影响现有玩法：提示框只负责说明，不参与魔方逻辑、计时、复原判断、排行榜保存。
- 不遮挡主要操作：第一版放右下角，避开顶部模式按钮、左侧操作按钮和右上角设置/排行榜。
- 操作明确：`知道了` 只关闭当前提示；`本次不再提示` 会关闭并在本次运行期间不再显示当前模式提示。
- 切换模式时更新内容：自动、练习、教学模式切换后显示对应说明。
- 后续可替换皮肤：第一版用 `fillroundrect` 等基础绘制，后续可改为图片背景。

## 推荐交互

- 从选择页进入 3 阶魔方时，根据当前默认模式显示自动模式提示。
- 点击顶部“自动模式 / 练习模式 / 教学模式”切换后，显示对应模式提示。
- 点击 `知道了`：关闭当前提示，下次切回当前模式仍会显示。
- 点击 `本次不再提示`：关闭当前提示，本次程序运行期间当前模式不再自动提示。
- 重新打开程序后，三个模式默认都会重新提示。
- 打开排行榜或设置面板时不额外改变提示框状态，按绘制层级覆盖即可。

## 提示框位置

第一版采用右下角方块提示框。

建议尺寸：

- `x = Width - 500`
- `y = Height - 310`
- `w = 460`
- `h = 260`

如果后续发现遮挡魔方过多，可以改成底部居中长条：

- `x = 360`
- `y = Height - 165`
- `w = Width - 720`
- `h = 120`

## 第一版文案

### 自动模式

标题：自动模式

正文：

- 点击“随机打乱”生成打乱状态。
- 点击“算法还原”使用层先法复原并开始计时。
- 点击“一键复位”可回到初始状态。
- 自动还原成绩以 PC 身份保存，可在排行榜查看。

### 练习模式

标题：练习模式

正文：

- 点击“随机打乱”后开始练习。
- 可打开公式面板，按国际配色公式复原。
- 也可用右键拖拽旋转外层。
- 开始复原后自动计时。
- 登录用户的成绩会保存到排行榜，游客不保存成绩。

注意：练习模式成绩当前代码保存到当前登录用户，不是 PC。

### 教学模式

标题：教学模式

正文：

- 准备一个真实魔方，将它打乱后，把各面的颜色填入教学魔方。
- 右键选择贴纸，贴纸会高亮；再左键选择颜色。
- 填色必须符合真实魔方规则，否则无法还原。
- 点击“人机对战”后开始复原，看一看谁更快？
- 点击“一键复位”可重新填写。
- 教学模式的算法还原成绩会以 PC 身份保存。

## 代码归属

建议把提示框作为 UI 组件放在 `ui` 模块，而不是直接写在 `game_play_page.cpp` 或某个模式文件里。

计划修改：

- `ui/ui.h`：新增 `ModeHelpPanel` 类声明。
- `ui/ui.cpp`：实现提示框绘制、两个按钮、固定多行文案。
- `game/game_state.h`：在 `GameUiState` 中新增 `ModeHelpPanel modeHelpPanel;`。
- `game/game_select_page.cpp`：进入 3 阶魔方时显示自动模式提示。
- `game/play/game_play_session.cpp`：切换模式时显示对应模式提示。
- `game/play/game_play_runtime.cpp`：在游戏页绘制提示框。

## 状态设计

`ModeHelpPanel` 建议包含这些状态：

```cpp
class ModeHelpPanel {
public:
    ModeHelpPanel();
    void showForMode(int mode);
    void hide();
    bool isVisible() const;
    bool draw(MOUSEMSG msg);

private:
    bool m_visible;
    int m_mode;
    bool m_suppressed[3];
};
```

不建议让 `ui.h` 直接依赖 `PlayMode`，用 `int mode` 可以降低头文件耦合。实现时约定：`0=自动模式`，`1=练习模式`，`2=教学模式`。

## 绘制细节

第一版提示框沿用当前木色 UI 风格：

- 背景色：`UIConfig::COL_PANEL_FILL`。
- 内部浅色区域：`UIConfig::COL_PANEL_INNER`。
- 边框色：`UIConfig::COL_PANEL_BORDER`。
- 标题：深棕色，字号 24 或 26。
- 正文：深棕色，字号 18。
- 按钮：普通木色按钮风格，使用 `知道了` 和 `本次不再提示`。
- 文案先用固定多行数组，不做自动换行，降低中文排版风险。

## 与现有流程的关系

### 进入游戏页

在选择页点击“3 阶魔方”后，设置当前模式为自动模式，并调用：

```cpp
g_ui.modeHelpPanel.showForMode(currentMode);
```

### 切换模式

在 `switchToMode(...)` 中，重建魔方并弹出“切换至...”短提示后，再调用：

```cpp
g_ui.modeHelpPanel.showForMode(mode);
```

### 绘制顺序

建议在游戏页后处理阶段绘制提示框，并让设置/排行榜在它之后绘制，保证浮层优先级更高。

```cpp
drawCurrentModeTabHighlight();
if (g_ui.modeHelpPanel.draw(msg)) {
    msg.uMsg = 0;
}
handleOverlayPanels();
```

## 分阶段实现

### 第一步：纯代码提示框

- 新增 `ModeHelpPanel`。
- 固定右下角位置。
- 三种模式对应固定多行文案。
- 支持 `知道了` 和 `本次不再提示`。
- 切换模式时自动显示。

### 第二步：调整文案和位置

- 根据实际运行截图压缩或拆分文字。
- 如果右下角遮挡魔方，改成底部居中长条。
- 根据可读性调整字号、行距和按钮位置。

### 第三步：图片皮肤

- 准备 `image/help_panel_bg.png` 或三种模式共用提示框图片。
- 复用现有 `ui/image` 绘制能力。
- 保留原来的文字绘制和按钮逻辑。

## 风险点

- 右下角可能遮挡魔方，需要测试后调整位置。
- 固定多行文案需要控制每行长度，避免超出框体。
- 提示框按钮点击应只消费自身事件，不影响其他浮层。
- 如果后续使用图片皮肤，需要注意透明 PNG 和缩放绘制问题。

## 建议优先实现版本

第一版按以下内容实现：

- 右下角方块提示框。
- 三种模式固定多行文案。
- 两个底部按钮：`知道了`、`本次不再提示`。
- 切换模式自动显示。
- 设置/排行榜不额外联动。

这个版本改动范围可控，主要集中在 `ui` 和少量 game 调用点，不会影响魔方核心逻辑。
